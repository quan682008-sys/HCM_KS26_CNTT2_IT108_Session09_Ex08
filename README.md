## Phần 1: Điền khuyết

- `#`: Tạo tiêu đề H1.
- ```` ```bash ````: Mở Code Block cho lệnh Bash.
- ```` ``` ````: Đóng Code Block.
- `-`: Tạo danh sách Task List.
- `--- | --- | ---`: Phân cách các cột trong bảng Markdown.
